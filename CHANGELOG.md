# Change Log

## 1.0.0

First public release of SonarCloud Stats.

- Quality gate, issues and coverage for the open workspace, straight from SonarCloud.
- Issues view with a "new since last look" filter and a baseline per workspace.
- Coverage decorations in the editor, a live coverage status bar and Go to Next Uncovered Line.
- Run `sonar-scanner` or the project's test command from the editor; cancelling stops the whole process group.
- Five language model tools for Copilot Chat agent mode: measures, issues, rules, coverage and scans.
